# MailTester

Windows-приложение для тестирования отправки SMTP и получения POP3. Интерфейс сохранён на Windows Forms.

## Сборка

Требуется Windows 10/11 (поддерживаемая .NET 10 версия) и .NET 10 SDK.

```powershell
dotnet --list-sdks
dotnet restore mailTester.csproj
dotnet build mailTester.csproj -c Release
dotnet run --project mailTester.csproj
```

Локальные smoke-тесты безопасности (без реальных учётных данных и внешних почтовых серверов):

```powershell
dotnet run --project tests/SecuritySmoke/SecuritySmoke.csproj -c Release
```

Portable x64 (самодостаточная публикация):

```powershell
dotnet publish mailTester.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
```

## Подключение

| Протокол | Порт | Шифрование |
| --- | --- | --- |
| SMTP | 587 / 25 | STARTTLS при включённой галочке |
| SMTP | 25 | Открытый текст только после явного подтверждения |
| POP3 | 995 | TLS 1.2/1.3 |
| POP3 | 110 | Открытый текст только после явного подтверждения |

SMTP implicit TLS на 465 и POP3 STLS пока не реализованы; IMAP и MailKit планируются отдельно. Сертификаты проверяются стандартными средствами платформы. Пароли не сохраняются в настройках приложения. Не используйте реальные рабочие пароли для тестов без шифрования.

## Безопасность

Ранее опубликованные секреты следует немедленно отозвать/заменить. Их удаление из новой версии не очищает предыдущие коммиты, форки, кэши и копии репозитория. История Git намеренно не переписана.

Вложения сохраняются только в выбранную папку с проверкой имени. При совпадении имени создаётся новый файл с числовым суффиксом. Вложения не запускаются автоматически.

## Ручные проверки

- После запуска поля адресов, серверов, логинов и паролей пусты; пароли скрыты.
- SMTP 587 с STARTTLS: успешная отправка, отказ при неверном пароле или недоверенном сертификате.
- POP3 995: успешное получение, отказ при неверном пароле или недоверенном сертификате; пароля нет в ошибке.
- Отключение шифрования требует подтверждения; 465 сообщает об отсутствии поддержки.
- Получение и повторное сохранение обычного вложения не перезаписывает файл.

Старое почтовое ядро пока сохранено; операции синхронные, а POP3 извлекает все сообщения. Переход на MailKit/MimeKit и асинхронные операции является следующей задачей.
