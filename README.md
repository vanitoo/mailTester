# MailTester 1.3

Windows Forms, .NET 10. SMTP, POP3 и IMAP на MailKit 4.18.2; MIME обрабатывает MimeKit 4.18.2 (зависимость MailKit).

## Интерфейс

- Обзор: показатели текущей сессии, переходы к SMTP, POP3/IMAP и журналу.
- SMTP: ввод параметров, переключение видимости пароля, письмо обычным текстом, добавление нескольких вложений и очистка списка.
- POP3/IMAP: поиск по теме и отправителю среди загруженных писем, дата, безопасный текстовый просмотр, сохранение вложений.
- Журнал: единая история операций, копирование, экспорт в TXT и очистка. Содержимое хранится в памяти, не сохраняется автоматически.
- Глобальный статус и таймер результата; отмена на кнопке активной операции.
- Светлая рабочая область, тёмное боковое меню, изменение размера окна и режим PerMonitorV2.

Показатели считаются с момента запуска (число принятых SMTP-сервером писем, число загруженных сообщений, включая повторные загрузки, ошибки запущенных операций). Не являются мониторингом доставки или доступности.

## Сборка и локальная проверка

```powershell
dotnet restore mailTester.csproj
dotnet build mailTester.csproj -c Release
dotnet run --project mailTester.csproj -c Release
dotnet run --project tests/SecuritySmoke/SecuritySmoke.csproj -c Release
dotnet list mailTester.csproj package --include-transitive --vulnerable
```

Portable x64:

```powershell
dotnet publish mailTester.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
```

## Подключение

| Протокол | Порт | Режим |
| --- | --- | --- |
| SMTP | 587 | STARTTLS |
| SMTP | 465 | SSL/TLS |
| SMTP | 25 | STARTTLS или Без TLS с подтверждением |
| POP3 | 995 | SSL/TLS |
| POP3 | 110 | STARTTLS (STLS) или Без TLS |
| IMAP | 993 | SSL/TLS |
| IMAP | 143 | STARTTLS или Без TLS |

При смене режима/протокола проставляется стандартный порт; его можно изменить. При пустых логине И пароле SMTP работает без AUTH (если сервер разрешает). Для получения требуется авторизация. Используйте пароль приложения, если провайдер его требует; OAuth2 пока не реализован.

Получение по IMAP открывает только INBOX с ReadOnly; POP3 не отправляет DELE. По умолчанию загружаются 25 последних по порядку сервера (1–200). Письма скачиваются целиком, без ограничения размера. HTML показывается текстом, активное содержимое не исполняется. Вложения декодируются MimeKit, сохраняются по безопасным именам без перезаписи; при ошибке часть предыдущих файлов может быть уже сохранена. Можно выбрать несколько файлов для отправки. Сетевые операции асинхронны, кнопка операции меняется на «Отмена», общий лимит 5 минут, сетевой таймаут 60 секунд. Принятие SMTP-сервером не гарантирует доставку в ящик.

TLS 1.2/1.3, стандартная проверка сертификата и имени хоста, без автоматического перехода к открытому тексту. Логи отображают только этап операции, тип ошибки и SMTP status code, без сырого сетевого диалога. Старые секреты следует отозвать; предыдущая история Git не переписана.

## Ручной smoke test

1. Отправить через SMTP 587/STARTTLS и 465/SSL; кириллица, несколько вложений.
2. Получить по POP3 995, IMAP 993; проверить тему, отправителя, тело и вложения, отсутствие признака прочтения у ранее непрочитанного IMAP-письма.
3. Проверить неверный пароль, недоверенный сертификат, сервер без STARTTLS и отмену подключения.
4. Сохранить одно вложение дважды: второй файл получает числовой суффикс.
5. Убедиться, что пароли не появляются в UI-журнале и что отмена не вызывает зависание.
6. При необходимости проверить relay без AUTH на собственном тестовом сервере.

Локальная сборка/сетевой smoke test выполняются на Windows. Диагностика DNS и полноценный протокольный журнал с редактированием секретов будут отдельными этапами.
